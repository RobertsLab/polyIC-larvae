1 Background

Oyster larvae in this experiment were exposed to poly:IC (a synthetic viral-infection mimic) and/or mechanical stress, crossed into six treatment groups: No_PolyIC_Control, No_PolyIC_Temperature, No_PolyIC_Mechanical, PolyIC_Control, PolyIC_Temperature, and PolyIC_Mechanical. Expression of eight candidate genes (ATP.Synthase, Citrate.Synthase, DNMT1, GAPDH, HSP70, HSP90, VIPERIN, cGAS) was measured by qPCR.

Before relative-expression (delta-Cq) analysis can be performed on any of these genes, a normalizing (reference) gene is needed – a gene whose raw Cq is stable across all treatment groups, so that it can be used to correct for sample-to-sample differences in input RNA/cDNA quantity. A gene that itself responds to treatment is not a valid normalizer, regardless of how technically consistent its measurement is.

This script identifies that normalizing gene. It:

  1. Loads and QCs the raw Cq data (removes NTC wells, flags high-variance technical replicates, removes outlier replicates).
  2. Summarizes raw Cq per sample/gene and parses treatment-group identity from sample names. For five genes (DNMT1, GAPDH, HSP90, VIPERIN, cGAS), PolyIC_Control draws on two complementary qPCR runs – an earlier run on Sam’s own biological samples and a 2026-10-08 run that filled in the remaining notebook samples – and both are kept, consistent with how every other treatment group already combines samples from multiple runs.
  3. Compares raw Cq distributions across all six treatment groups for each gene via one-way ANOVA with Tukey HSD post-hoc testing.
  4. Ranks the eight candidate genes by coefficient of variation (CV%) of raw Cq, and flags any gene whose raw Cq differs significantly across treatment groups.

The gene identified here as the most stable, treatment-insensitive candidate is carried forward as the normalizing gene in a separate downstream relative-expression analysis script.

5 Parse Sample Names and Add Treatment Columns

Sample naming convention: Letter + Number + P (optional) + Treatment

  • Letter: Biological replicate
  • Number: Replicate number
  • P: PolyIC treatment (absent if no PolyIC)
  • C/T/M: Control/Temperature/Mechanical stress
# Parse sample names to extract treatment information
grouped_df <- grouped_df %>%
  mutate(
    # Extract biological replicate (first letter)
    bio_replicate = str_extract(Sample, "^[A-Z]"),
    
    # Extract replicate number
    replicate_num = str_extract(Sample, "\\d+"),
    
    # Check if PolyIC treatment (contains P)
    polyIC = ifelse(str_detect(Sample, "P"), "PolyIC", "No_PolyIC"),
    
    # Extract stress type (last letter: C, T, or M)
    stress_type = case_when(
      str_detect(Sample, "C$") ~ "Control",
      str_detect(Sample, "T$") ~ "Temperature",
      str_detect(Sample, "M$") ~ "Mechanical",
      TRUE ~ NA_character_
    ),
    
    # Create combined treatment group
    treatment_group = paste(polyIC, stress_type, sep = "_")
  )

6 Raw Cq Variation Assessment for Normalizing Gene Selection

This section evaluates raw Cq values (i.e., prior to any delta-Cq normalization) for each gene, using the post-QC, per-sample mean Cq already calculated in grouped_df (Cq.Mean = mean of technical replicates per Sample x Target, after NTC removal, high Std. Dev. filtering, and outlier technical-replicate removal above). The goal is to identify which gene varies least across samples/treatment groups, since a low and consistent raw Cq across all conditions is the defining property of a good normalizing (“housekeeping”) gene. Genes whose expression itself responds to treatment are poor normalizers, even if technically “stable” in a QC sense.

Box plots and statistical group comparisons below include every gene, including those missing some sample-gene combinations and/or with samples dropped for QC (Std. Dev. or outlier-replicate filtering). Treatment-group sample sizes are therefore unequal for genes with missing data – the completeness table immediately below reports exactly how many samples are missing/dropped per gene, so that result should be read alongside the box plots and ANOVA results for those genes.

6.3 Box plots and statistical comparisons: raw Cq by treatment group (all genes)

treatment_order <- c("No_PolyIC_Control", "No_PolyIC_Temperature", "No_PolyIC_Mechanical",
                      "PolyIC_Control", "PolyIC_Temperature", "PolyIC_Mechanical")

rawcq_all_df <- grouped_df %>%
  mutate(treatment_group = factor(treatment_group, levels = treatment_order))

# One-way ANOVA per gene (Cq.Mean ~ treatment_group) with Tukey HSD post-hoc and
# a Compact Letter Display (CLD) for plot annotation. `emmeans:::cld.emmGrid` is
# called directly (rather than the `multcomp::cld()` generic) because the S3 method
# dispatch for emmGrid objects is sensitive to package load order in some sessions.
# Treatment-group sample sizes are unbalanced for genes with missing data (see the
# completeness table above); `aov`/`TukeyHSD`/`emmeans` all handle unbalanced designs,
# but statistical power is reduced for groups with few observations.
rawcq_anova_models <- list()
rawcq_tukey <- list()
rawcq_cld <- data.frame()

for (gene in rawcq_all_genes) {
  gene_df <- rawcq_all_df %>% filter(Target == gene)
  mod <- aov(Cq.Mean ~ treatment_group, data = gene_df)
  rawcq_anova_models[[gene]] <- mod
  rawcq_tukey[[gene]] <- TukeyHSD(mod)

  emm <- emmeans(mod, ~ treatment_group)
  cld_df <- as.data.frame(emmeans:::cld.emmGrid(emm, Letters = letters, alpha = 0.05))
  cld_df$Target <- gene
  cld_df$label <- trimws(cld_df$.group)
  rawcq_cld <- rbind(rawcq_cld, cld_df[, c("Target", "treatment_group", "label")])
}

rawcq_cld <- rawcq_cld %>%
  mutate(treatment_group = factor(treatment_group, levels = treatment_order))
