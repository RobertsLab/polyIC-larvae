### qPCR Reports

`report-*.pdf` files are generated from the [source `.pcrd` files](../cfx_files/). Contain plate layout, cycling parameters, amplification plots, and melt curves.

Every `.pcrd` file in [`../cfx_files/`](../cfx_files/) has a corresponding report here.
